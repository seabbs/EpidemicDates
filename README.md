Line lists often have cases with a report date but no onset date.
A common fix is to give each one an onset drawn back from its report date using the delays of cases with both dates (back-sampling).
This project compares that with other methods, and shows when each one biases the onset curve and its growth rate, for example when growth or delays change.
It started from a discussion in [BDBV-Modeling-Hub issue #61](https://github.com/InsightNet-US/BDBV-Modeling-Hub/issues/61).

- **Docs:** <https://seabbs.github.io/EpidemicDates/>
- **Interactive page:** <https://seabbs.github.io/EpidemicDates/interactive/>

## Methods

| Method | What it does |
|---|---|
| Back-sampling | Subtracts a delay drawn from the pooled delays of cases with both dates. |
| Mean shift | Subtracts the mean of those delays. |
| Forward draw | Subtracts a delay drawn from the onset-to-report delay. |
| Generative (EM back-projection) | Shares each missing case over onset days by the onset curve times the delay, re-estimating both. |

The [methods page](https://seabbs.github.io/EpidemicDates/methods/) gives the maths, and the [assumptions page](https://seabbs.github.io/EpidemicDates/assumptions/) says what each method relies on.

Python and JavaScript also have a nowcast with uncertainty.
Python has the simulation study and an optional JAX layer for NumPyro models (`pip install "epidemic-dates[jax] @ git+https://github.com/seabbs/EpidemicDates"`).

## Quick start

Impute the missing onsets in a line list, in Python:

```python
import numpy as np
import epidemic_dates as ed

onset = np.array([0, 2, np.nan, 5, np.nan])  # NaN where the onset is missing
report = np.array([3, 6, 7, 9, 12])
res = ed.impute_linelist(onset, report, cutoff=12)
res["imputed"]["em"]  # daily onset counts after imputation
```

The [worked example](https://seabbs.github.io/EpidemicDates/real-linelist/) goes through an example line list in all four languages, and nowcasts the recent weeks.

## Development

Requires [uv](https://docs.astral.sh/uv/), Node 20 or later, R, Julia and [Task](https://taskfile.dev).

```bash
task setup    # install JavaScript, Python and Julia dependencies
task test     # JavaScript and Python tests, including the cross-language check
task lint     # ESLint, prettier, type checks, ruff and mypy
task r-test   # R tests (also r-check and r-lint)
task julia-test
task test-jax # the optional JAX layer, including a NumPyro fit
task docs     # build the docs into _site/, with the page at _site/interactive/
task serve    # serve the page on http://localhost:8000
```
