# ![EpidemicDates for JavaScript](../assets/logo-wordmark-js.svg#only-light){ .title-logo width="267" height="44" } ![](../assets/logo-wordmark-js-dark.svg#only-dark){ .title-logo width="267" height="44" }

Load `epidemic-dates.js` with `require` in Node, or use the global `EpidemicDates` in a browser.
{ .page-subtitle }

The JavaScript module `epidemic-dates.js` holds the maths behind the [interactive page](https://seabbs.github.io/EpidemicDates/interactive/).
It simulates an epidemic in expectation, imputes the missing onsets four ways and compares each with the truth.
It can also impute a real line list.
It has no dependencies.

- Source: [`epidemic-dates.js`](https://github.com/seabbs/EpidemicDates/blob/main/epidemic-dates.js)
- Every function and type: [API reference](reference.md)
- The maths: [Methods](../methods.md)
- What it relies on: [Assumptions](../assumptions.md)

## Load it

In a browser, the script defines the global `EpidemicDates`:

```html
<script src="epidemic-dates.js"></script>
<script>
  const res = EpidemicDates.run();
</script>
```

In Node 20 or later:

```js
const EpidemicDates = require("./epidemic-dates.js");
```

## Quick start on your own data

This reads the [example line list](../data/example-linelist.csv), imputes the missing onsets and prints weekly onset counts by method.

```js
const fs = require("node:fs");
const { imputeLinelist } = require("./epidemic-dates.js");

const t0 = Date.parse("2026-05-08"); // earliest date in the file
const day = (x) => (x ? (Date.parse(x) - t0) / 86400000 : null);
const rows = fs
  .readFileSync("docs/data/example-linelist.csv", "utf8")
  .trim()
  .split(/\r?\n/)
  .slice(1)
  .map((line) => line.split(","));
const onset = rows.map((r) => day(r[1]));
const report = rows.map((r) => day(r[2]));
const res = imputeLinelist({ onset, report, cutoff: Math.max(...report) });
for (const m of ["backsampling", "mean", "gen"]) {
  const weeks = [];
  res.imputed[m].forEach((x, i) => {
    const w = Math.floor(i / 7);
    weeks[w] = (weeks[w] ?? 0) + x;
  });
  console.log(m, weeks.map((x) => x.toFixed(1)).join(" "));
}
```

mean 4.0 0.0 5.0 6.0 6.0 11.0 19.0 29.0 34.0 43.0 43.0 62.0 55.0 53.0 38.0 25.0 4.0
gen 4.2 0.0 2.5 7.8 7.0 10.1 20.0 27.3 35.9 43.7 41.0 65.7 54.2 50.1 37.5 24.8 5.1

The [worked example](../real-linelist.md) explains each step.

`imputeLinelist` takes one object ([`LinelistInput`](reference.md#module_epidemic-dates.LinelistInput)) with:

- `onset`: onset day per case, `null` where missing;
- `report`: report day per case;
- `cutoff`: the last report day to use, by default the latest;
- `delay`: a forward delay pmf indexed by day, to hold the delay fixed and to fill in the forward draw;
- `maxDelay` and `iterations`: the longest delay kept and the number of EM iterations.

It returns a [`LinelistResult`](reference.md#module_epidemic-dates.LinelistResult).
`imputed` holds daily onset counts for `backsampling`, `mean`, `fwd` and `gen`.
`fwd` is `null` without `delay`.
`generativeDelay` is the delay used or estimated by EM.

## Nowcast with uncertainty

[`nowcastLinelist`](reference.md#module_epidemic-dates.nowcastLinelist) imputes the missing onsets, corrects for right truncation and samples to give quantiles.
This continues the quick start above.

```js
const { nowcastLinelist } = require("./epidemic-dates.js");

const nc = nowcastLinelist({
  onset,
  report,
  method: "gen",
  seed: 1,
  origin: "2026-05-08"
});
for (const r of nc.weeklyQuantiles.slice(-7)) {
  console.log(r.week_start, r.target_end_date, r.quantile, r.value);
}
```

```text
2026-08-18 2026-08-24 0.025 39
2026-08-18 2026-08-24 0.1 42
2026-08-18 2026-08-24 0.25 45
2026-08-18 2026-08-24 0.5 48
2026-08-18 2026-08-24 0.75 51
2026-08-18 2026-08-24 0.9 55
2026-08-18 2026-08-24 0.975 58
```

The table has one row per week and quantile.
Weeks end on the cut-off.
The week ending on the cut-off has no estimate, because under 5% of the cases with onset that day are reported (`minReported`).
`method` can also be `backsampling`, `mean` or `fwd`, and `delay` holds the delay fixed.
The point nowcast matches Python's `nowcast_linelist`, but the random draws differ.
The bands include the draw of missing onsets, the cases not yet reported and, by resampling, uncertainty in the delay.
They do not include a delay that changes over time.
See [Step 6 of the worked example](../real-linelist.md#step-6-nowcast-the-recent-weeks) and the [Methods](../methods.md#nowcast-with-uncertainty).

## Simulate a scenario and compare the methods

`run()` simulates an epidemic, imputes the missing onsets four ways and compares each with the truth.
Every parameter has a default in `EpidemicDates.DEFAULTS`.
Pass only what you want to change.
The parameters are listed under [`ScenarioParams`](reference.md#module_epidemic-dates.ScenarioParams).

```js
const { run, knotsFrom } = EpidemicDates;

const res = run({
  knots: knotsFrom([[0, 0.05], [60, 0.05], [110, -0.01], [175, 0.03]]), // growth rate per day
  mu0: 6.6, mu1: 6.6, cv: 0.92,   // onset-to-report delay: mean at start and end, CV
  pi0: 0.15, pi1: 0.15,           // fraction of onsets missing at start and end
  retro: false, cutoff: 179,      // cut the data at day 179 (real time)
  nowcast: true                   // correct every method for right truncation
});

res.truth;               // weekly true onsets
res.imputed.backsampling;         // weekly onsets after imputation: backsampling, mean, fwd, gen
res.rt.backsampling;              // weekly Rt from the imputed counts
res.metrics.backsampling.maxRel;  // largest weekly relative error
res.metrics.backsampling.maxR;    // largest Rt error
```

The result is a [`RunResult`](reference.md#module_epidemic-dates.RunResult).
The error measures are described under [`Metrics`](reference.md#module_epidemic-dates.Metrics).

## The page's scenarios

The scenarios on the page are in `EpidemicDates.PRESETS`.
This prints the largest weekly relative error of the back-sampling and generative methods for each one:

```js
for (const p of EpidemicDates.PRESETS) {
  const m = run(p.set).metrics;
  console.log(p.name.padEnd(40), m.backsampling.maxRel.toFixed(3), m.gen.maxRel.toFixed(3));
}
```

The generative method is unbiased in most scenarios because it is given the true delay.
It is biased in "Late cases miss onsets", where missingness depends on the delay and every method fails.
It is also off in "Longer delays: 14 days, 70% missing".

## Building blocks

- [`delayPmf(mu, cv)`](reference.md#module_epidemic-dates.delayPmf) gives a double interval censored daily Gamma delay pmf.
- [`rToR(r)`](reference.md#module_epidemic-dates.rToR) turns a growth rate into Rt.
- [`convImpute`](reference.md#module_epidemic-dates.convImpute), [`shiftImpute`](reference.md#module_epidemic-dates.shiftImpute) and [`emImpute`](reference.md#module_epidemic-dates.emImpute) are the imputation methods on daily counts.
- [`stochastic`](reference.md#module_epidemic-dates.stochastic) runs Poisson replicates and returns 90% bands.

```js
const f = EpidemicDates.delayPmf(8, 1); // mean 8 days, CV 1
EpidemicDates.pmfMean(f);               // 8.00
EpidemicDates.rToR(0.05);               // 1.94
```
