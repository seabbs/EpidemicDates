# Python guide

The Python package `epidemic_dates` is an independent stochastic simulation.
It cross-checks the expected-value maths in the [JavaScript module](../javascript/index.md) that drives the [interactive page](https://seabbs.github.io/epidemic-imputation-demonstration/).
It can also impute a real line list.

- Source: [`src/epidemic_dates/`](https://github.com/seabbs/epidemic-imputation-demonstration/tree/main/src/epidemic_dates)
- Every function: [API reference](reference.md)
- The maths: [Methods](../methods.md)
- What it relies on: [Assumptions](../assumptions.md)

## Quick start on your own data

This reads the [example line list](../data/example-linelist.csv), imputes the missing onsets and prints weekly onset counts by method.

```python
import csv
import datetime as dt

import numpy as np
import epidemic_dates as oi

np.set_printoptions(linewidth=100)

day0 = dt.date(2026, 5, 8)  # earliest date in the file
def day(x):
    return (dt.date.fromisoformat(x) - day0).days if x else np.nan

with open("docs/data/example-linelist.csv") as fh:
    rows = list(csv.DictReader(fh))
onset = np.array([day(r["onset_date"]) for r in rows])
report = np.array([day(r["report_date"]) for r in rows])
res = oi.impute_linelist(onset, report, cutoff=int(report.max()))
week = np.arange(int(report.max()) + 1) // 7
for m in ["hub", "mean", "em"]:
    print(m, np.bincount(week, weights=res["imputed"][m]).round(1))
```

```text
hub [ 4.2  0.5  3.2  6.8  7.2 10.6 19.8 27.3 35.5 43.4 41.9 63.2 54.  50.5 38.6 25.4  5. ]
mean [ 4.  0.  5.  6.  6. 11. 19. 29. 34. 43. 43. 62. 55. 53. 38. 25.  4.]
em [ 4.2  0.   2.5  7.8  7.  10.1 20.  27.3 35.9 43.7 41.  65.7 54.2 50.1 37.5 24.8  5.1]
```

The [worked example](../real-linelist.md) explains each step.

`impute_linelist` takes:

- `onset`: onset day per case, `NaN` where missing;
- `report`: report day per case, never missing;
- `cutoff`: the last report day to use, by default the latest;
- `n_iter`: the number of EM iterations.

It returns a dict.
`imputed` holds daily onset counts for `hub`, `mean` and `em`.
`complete` holds the cases with a known onset, `missing_by_report` the missing-onset cases by report day, and `empirical_delay` the pooled delay pmf.
`dropped` counts cases that could not be used.

## Run the simulation study

The study simulates each scenario many times and measures the bias of each method.
From the command line, results go to `output/results.csv`:

```bash
epidemic-dates --reps 200 --out output
epidemic-dates --reps 50 --scenarios C W
```

The options are `--reps`, `--seed`, `--out` and `--scenarios`.

From Python, run one scenario:

```python
import epidemic_dates as oi

oi.DESC["W"]                           # 'two waves: growth, control, ...'
rows = oi.run_scenario("W", reps=100)  # one row per cut-off and method
for r in rows:
    print(r["cutoff"], r["method"], r["relbias_mean"], r["relbias_maxabs"])
```

Each row has the scenario, cut-off, method and bias summaries.
`relbias_mean` and `relbias_maxabs` are the mean and largest absolute relative bias in weekly counts.
Columns starting `gr_` measure bias in the growth rate.
See [`run_scenario`][epidemic_dates.run_scenario] in the API reference for every column.

Run every scenario and write the results:

```python
rows = oi.run_study(reps=200)
oi.write_results(rows, "output")
print("\n".join(oi.analytic()))   # checks of the steady-growth result
```

## Scenarios

`oi.SCEN` holds each scenario's settings and `oi.DESC` a one-line description.
Unless stated, the delay is `F_DEFAULT` (mean 8 days, SD 8 days) and each onset is missing with probability 0.4.

| Name | Description |
|---|---|
| `A` | r = 0.05 constant |
| `B` | r = 0.05, then −0.03 from day 60 |
| `B0` | r = 0, stable |
| `C` | r from 0.05 to −0.02 over days 60 to 100 |
| `D` | r from 0.06 to −0.04 at day 80 |
| `E` | r = 0.008 (Isiro-like) |
| `F` | r = 0.03, mean delay falls from 12 to 4 days |
| `G` | as `C`, with P(missing) rising from 0.2 to 0.7 with the delay |
| `H` | as `C`, with P(missing) rising from 0.2 to 0.6 by report day 60 to 100 |
| `I` | as `C`, with ascertainment doubling at day 70 |
| `Csmall` | as `C`, with about 300 cases |
| `W` | two waves: growth, control, resurgence, control |

To simulate one line list yourself:

```python
import numpy as np

sp = oi.scenario_setup("C")
onset, report, missing = oi.simulate("C", sp, np.random.default_rng(1))
```

## Building blocks

- `gamma_pmf(mean, sd)` gives a double interval censored daily Gamma delay pmf on `0..DMAX`.
- `em_backproject` runs EM back-projection on complete and missing-onset cases.
- `METHODS` lists the methods compared and `DMAX` the maximum delay.
