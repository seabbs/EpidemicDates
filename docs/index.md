# Comparing methods for imputing missing symptom onsets

Line lists often lack an earlier event date for some cases, such as the date of symptom onset, infection or sampling.
A later date, such as the report date, is usually known.
These tools reconstruct the missing earlier date from the later one and allow for right truncation.
The worked examples use symptom onsets reconstructed from report dates.

The project began by asking how biased one common approach is.
That approach fills a missing onset with the report date minus a delay drawn from the pooled empirical onset-to-report delays.
It is discussed in [BDBV-Modeling-Hub issue #61](https://github.com/InsightNet-US/BDBV-Modeling-Hub/issues/61).
The project compares it with three other methods.

Both languages can also impute a [real line list](real-linelist.md).

## The methods

| Key | Method |
|---|---|
| `hub` | Draw a delay from the pooled empirical delays of cases with both dates. |
| `mean` | Shift by the rounded mean empirical delay. |
| `fwd` / `forward` | Draw a delay from the forward delay distribution. |
| `gen` / `em` | EM back-projection, a partial deconvolution of the missing-onset cases. |

The JavaScript keys come first and the Python keys second where they differ.
See [Methods](methods.md) for the maths and [Assumptions](assumptions.md) for what each result relies on.

## Quick start on your own data

The example line list [`example-linelist.csv`](data/example-linelist.csv) has one row per case.
Its columns are `case_id`, `onset_date` and `report_date`, with `onset_date` empty where it is missing.
These snippets impute the missing onsets and print weekly onset counts for each method.
Run them from the repository root.

=== "Python"

    ```python
    import csv
    import datetime as dt

    import numpy as np
    import onset_imputation as oi

    np.set_printoptions(linewidth=100)

    day0 = dt.date(2026, 5, 8)  # earliest date in the file
    def day(x):
        return (dt.date.fromisoformat(x) - day0).days if x else np.nan

    with open("docs/data/example-linelist.csv") as fh:
        rows = list(csv.DictReader(fh))
    onset = np.array([day(r["onset_date"]) for r in rows])
    report = np.array([day(r["report_date"]) for r in rows])
    res = oi.impute_linelist(onset, report, cutoff=int(report.max()))
    week = np.arange(int(report.max()) + 1) // 7
    for m in ["hub", "mean", "em"]:
        print(m, np.bincount(week, weights=res["imputed"][m]).round(1))
    ```

    ```text
    mean [ 4.  0.  5.  6.  6. 11. 19. 29. 34. 43. 43. 62. 55. 53. 38. 25.  4.]
    em [ 4.2  0.   2.5  7.8  7.  10.1 20.  27.3 35.9 43.7 41.  65.7 54.2 50.1 37.5 24.8  5.1]
    ```

=== "JavaScript"

    ```js
    const fs = require("node:fs");
    const { imputeLinelist } = require("./onset-imputation.js");

    const t0 = Date.parse("2026-05-08"); // earliest date in the file
    const day = (x) => (x ? (Date.parse(x) - t0) / 86400000 : null);
    const rows = fs
      .readFileSync("docs/data/example-linelist.csv", "utf8")
      .trim()
      .split(/\r?\n/)
      .slice(1)
      .map((line) => line.split(","));
    const onset = rows.map((r) => day(r[1]));
    const report = rows.map((r) => day(r[2]));
    const res = imputeLinelist({ onset, report, cutoff: Math.max(...report) });
    for (const m of ["hub", "mean", "gen"]) {
      const weeks = [];
      res.imputed[m].forEach((x, i) => {
        const w = Math.floor(i / 7);
        weeks[w] = (weeks[w] ?? 0) + x;
      });
      console.log(m, weeks.map((x) => x.toFixed(1)).join(" "));
    }
    ```
