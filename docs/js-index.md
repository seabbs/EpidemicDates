# onset-imputation.js

Comparing methods for imputing missing symptom onsets: the JavaScript module behind the [interactive page](https://seabbs.github.io/epidemic-imputation-demonstration/).

> **Warning.** This code was generated by an LLM. Sam Abbott has only checked the interactive page. Treat the results as exploratory.

It has no dependencies. See the [module reference](module-onset-imputation.html) for every function, the maths of each method, and the parameters.

## Load it

In a browser, the script defines a global `OnsetImputation`:

```html
<script src="onset-imputation.js"></script>
<script>
  const res = OnsetImputation.run();
</script>
```

In Node:

```js
const OnsetImputation = require("./onset-imputation.js");
```

## Simulate a scenario and compare the methods

`run()` simulates an epidemic, imputes the missing onsets four ways and compares each with the truth.
Every parameter has a default (`OnsetImputation.DEFAULTS`); pass only what you want to change.

```js
const { run, knotsFrom } = OnsetImputation;

const res = run({
  knots: knotsFrom([[0, 0.05], [60, 0.05], [110, -0.01], [175, 0.03]]), // growth rate per day
  mu0: 6.6, mu1: 6.6, cv: 0.92,   // onset-to-report delay: mean at start and end, CV
  pi0: 0.15, pi1: 0.15,           // fraction of onsets missing at start and end
  retro: false, cutoff: 179,      // cut the data at day 179 (real time)
  nowcast: true                   // correct every method for right truncation
});

res.truth;               // weekly true onsets
res.imputed.hub;         // weekly onsets after imputation: hub, mean, fwd, gen
res.rt.hub;              // weekly Rt from the imputed counts
res.metrics.hub.maxRel;  // largest weekly relative error
res.metrics.hub.maxR;    // largest Rt error
```

The page's scenarios are in `OnsetImputation.PRESETS`:

```js
for (const p of OnsetImputation.PRESETS) {
  const m = run(p.set).metrics.hub;
  console.log(p.name, m.maxRel, m.maxR);
}
```

## Impute a real line list

`imputeLinelist()` takes one onset day (or `null`) and one report day per case, as whole numbers such as days since the first report.

```js
const res = OnsetImputation.imputeLinelist({
  onset: [0, 2, null, 5, null],
  report: [3, 6, 7, 9, 12],
  cutoff: 12
});

res.imputed.hub;       // daily onset counts, pooled empirical delays
res.imputed.mean;      // daily onset counts, mean shift
res.imputed.gen;       // daily onset counts, EM back-projection
res.generativeDelay;   // delay estimated by EM, allowing for right truncation
```

Pass `delay` (a pmf indexed by day) to hold the delay fixed and to get the forward draw in `res.imputed.fwd`.
Read the assumptions in the [README](https://github.com/seabbs/epidemic-imputation-demonstration#using-it-on-a-real-line-list) before relying on the output.
