# epidemicdates

Impute missing symptom onsets in an epidemic line list from R.

`epidemicdates` is the R version of the core line-list tools in this repository.
It matches the Python package `epidemic_dates` and the JavaScript module `epidemic-dates.js`.
It compares four ways to fill in a missing onset date from the report date.

- `backsampling`: draw a delay from the pooled empirical delays of cases with both dates.
- `mean`: move each case back by the mean empirical delay.
- `fwd`: draw a delay from a forward delay you give.
- `em`: EM back-projection with a static delay, allowing for right truncation.

## Use

```r
library(epidemicdates)

onset <- c(0, 2, NA, 5, NA)
report <- c(3, 6, 7, 9, 12)
res <- impute_linelist(onset, report, cutoff = 12)

res$imputed$backsampling # daily onsets after back-sampling
res$imputed$em           # daily onsets after EM back-projection
weekly(res$imputed$em)   # summed to weeks
```

`impute_linelist()` also takes `Date` vectors.
Days then count from the earliest date.

Other functions:

- `delay_pmf()` gives a double interval censored daily Gamma delay pmf.
- `correct_truncation()` corrects daily onset counts for right truncation.
- `weekly()` sums daily counts to weeks.

All methods assume onsets are missing at random given the report day.
